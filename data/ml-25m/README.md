# MovieLens 25M Dataset

This folder should contain the MovieLens 25M dataset for the recommender system example.

## Download Instructions

1. Download from: https://grouplens.org/datasets/movielens/25m/
2. Extract `ml-25m.zip`
3. Place the following files in this folder:
   - `movies.csv`
   - `ratings.csv`

## Usage

After downloading, run the recommender system demo:
```bash
cd examples/recommender_system
python demo_recommender_system.py
```
